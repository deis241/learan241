4.5 TRIANGLE DE PASCAL
=======================

Le triangle de Pascal est un arrangement des coefficients binomiaux :
a la ligne i et a la colonne j (0 <= j <= i), on trouve le coefficient
binomial C(i, j).

    1
    1 1
    1 2 1
    1 3 3 1
    1 4 6 4 1
    1 5 10 10 5 1
    ...

Regle de construction :
- les extremites de chaque ligne valent toujours 1
- chaque autre nombre est la somme des deux nombres juste au-dessus
  de lui, dans la ligne precedente

Representation : un tableau a deux dimensions (n lignes, n colonnes),
initialise a 0, que l'on remplit ligne par ligne.


--- Algorithme ---

ALGORITHME TriangleDePascal
DONNEES : n (entier, nombre de lignes a generer)
RESULTAT : affiche les n premieres lignes du triangle de Pascal

DEBUT
    LIRE n

    SI n < 1 ALORS
        ECRIRE "Le nombre de lignes doit etre superieur ou egal a 1"
    SINON
        DECLARER triangle[n][n] initialise a 0

        POUR i DE 0 A n - 1 FAIRE
            triangle[i][0] <- 1
            triangle[i][i] <- 1

            POUR j DE 1 A i - 1 FAIRE
                triangle[i][j] <- triangle[i - 1][j - 1] + triangle[i - 1][j]
            FIN POUR
        FIN POUR

        POUR i DE 0 A n - 1 FAIRE
            POUR j DE 0 A i FAIRE
                ECRIRE triangle[i][j], " "
            FIN POUR
            ECRIRE SAUT DE LIGNE
        FIN POUR
    FIN SI
FIN


--- Cas particuliers a gerer ---

- n = 0 ou negatif       -> rien a afficher, message d'erreur
- n = 1                  -> une seule ligne : "1"
- i = 0 (premiere ligne) -> pas de boucle interne (0 <= j <= i - 1 est vide),
                             triangle[0][0] deja mis a 1
- affichage              -> n'afficher que la partie utile de chaque ligne
                             (colonnes 0 a i), pas les zeros de remplissage
